-원형 연결 리스트란?
시작 위치와 다음 위치가 계속 이어진 후 마지막 노드가 다시 처음 노드를 가리키는 형태.
원형 연결 리스트는 노드에 None이 없음. 만약 노드가 하나밖에 없다면 그 노드는 자기 자신을 가리킨다.

-스택의 개념
한 쪽 끝이 막힌 형태로 입구가 하나이기 때문에 먼저 들어간 것이 가장 나중에 나오는 구조임.

-여태까지 했던 것 돌아보기-

-1장-

-자료구조란? 자료를 효율적으로 관리하는 방법

-알고리즘이란? 목적지까지 최적의 이동 경로를 찾는 방법
알고리즘의 성능 측정 방법은 시간 복잡도를 사용하는 한다. 표기법으로는 대표적으로 빅-오(Big-Oh Notation)표기법이 있다

자료구조에는 크게 네가지가 있다
단순 자료구조, 선형 자료구조, 비선형 자료구조, 파일 자료구조로 나뉜다.

-선형 자료구조란? 데이터를 한 줄로 순차적으로 표현한 형태로 예를 들어 선형 리스트, 연결 리스트, 스택, 큐 등이 있다.

-비선형 자료구조란? 하나의 데이터 뒤에 여러 개가 이어지는 형태로 예를 들어 트리와 그래프 등이 있다.

-3장 ~ 4장-

-선형 리스트란? 일열로 줄을 서는 구조를 갖고있다. 데이터가 순서대로 나열된 것.

-단순 연결 리스트란? 떨어진 곳에 위치한 데이터를 화살표로 연결한 것(흩어진 데이터들이 서로 이어져있기 때문에 하나만 찾으면 나머지의 위치를 알 수 있도록 구조 되어있음.)

(단순 연결 리스트의 원리)
노드 구조
-단순 연결 리스트는 다음 데이터를 가리키는 링크가 더 필요함.
-노드는 데이터와 링크로 구성된 항목.
첫번째 노드는 다음 노드의 주소에 입력되고 만약에 마지막 노드라면 None이 된다.

-단순 연결 리스트의 일반 형태
노드를 저장하는 메모리가 필요했고 head, pre, current라는 변수가 필요하다. 이것이 필요한 이유는 첫번째 노드는 기억하지 못하기 때문에 head라는 변수를 이용하여 첫번째 노드가 어디있는지 찾는 용도로 사용하고 작업하는 노드를 가리킬 때 current를 사용한다. pre는 무조건 현재 작업하고 있는 노드의 앞에 노드를 가리킨다
